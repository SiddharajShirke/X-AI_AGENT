# Skill index

- `architecture` — Plan or review changes that cross multiple Startup X Agent components.
- `scheduler` — Change the ten-slot scheduler, timezone behavior, or approval timeout processing.
- `trend-collector` — Add or change manual, RSS, X, competitor, or news research signals.
- `content-generation` — Change prompts, the GroqWriter, or the credential-free demo writer.
- `safety-guard` — Change never-reveal, banned language, length, or disclosure detection.
- `feedback-loop` — Change rejection, edit, approval examples, learned preferences, or regeneration memory.
- `approval-flow` — Change dashboard, API, Telegram, edit, reject, timeout, or approve state transitions.
- `x-publisher` — Change dry-run or Buffer-based X publication behavior.
- `dashboard` — Change the server-rendered configuration and human review dashboard.
- `testing` — Add or improve tests for the Startup X Agent prototype.
- `deployment` — Change Docker, environment, startup scripts, packaging, or hosted prototype instructions.
